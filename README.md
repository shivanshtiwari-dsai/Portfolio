# Shivansh Tiwari — Engineering & Design Portfolio

A bespoke, dark-editorial developer portfolio engineered with modern front-end craftsmanship and interactive visual architecture. Built for Shivansh Tiwari — B.Tech Computer Science Engineering (Data Science & AI) student at Shri Ramswaroop Memorial University (SRMU).

## 🚀 Live Demo
Visit the live site: [https://shivanshtiwari-dsai.github.io/Portfolio/](https://shivanshtiwari-dsai.github.io/Portfolio/)

---

## ✨ Design & Interaction Highlights
- **Asymmetrical Editorial Hero**: Featuring a live Indian Standard Time (IST) clock, typing text animation, and an interactive developer code terminal simulator (`profile.json`, `stack.ts`, `shivi_ai.py`).
- **Academic & Identity Bento Grid**: 4-part storytelling Bento layout showcasing philosophy, SRMU B.Tech CSE (DS+AI) curriculum, and the intersection between data science and UI/UX engineering.
- **Categorized Technical Arsenal**: Filterable capability matrix with custom mastery tiers, tags, and category tabs (no generic percentage bars).
- **Flagship Project Showcase — SHIVI AI**: Asymmetrical spotlight with deep architectural breakdown and an **interactive in-portfolio chatbot simulator** allowing visitors to test conversational responses in real-time.
- **Fluid Custom Cursor**: Smooth trailing ring and interactive focus transitions (automatically disabled on touch devices).
- **Circular Scroll Progress**: Floating back-to-top button with an SVG progress ring tracking scroll depth.
- **Zero Heavy Framework Overhead**: Built with pure, semantic HTML5, modern CSS3 (Custom Properties & Grid), and modular vanilla JavaScript (ES6+).

---

## 🛠️ Tech Stack & Architecture
- **Semantic HTML5**: Full ARIA landmark compliance, Open Graph, and SEO metadata.
- **CSS3 Design System**: Custom dark obsidian color tokens, glassmorphism, responsive Grid/Flexbox layouts, and keyframe animations.
- **Modular Vanilla JS**: Encapsulated modules for navigation, scroll tracking, typing effects, live clocks, clipboard utilities, and interactive chat simulation.
- **Typography**: Google Fonts pairing — *Space Grotesk*, *Plus Jakarta Sans*, and *JetBrains Mono*.
