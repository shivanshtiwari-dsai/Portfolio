## ✨ Key Architectural & Design Features

### 1. 🛡️ 100% Self-Contained Architecture (Zero Load Failure)
- Engineered to be completely self-contained with inlined CSS styles and JavaScript directly embedded in `index.html`, alongside synchronized modular external companion files (`style.css` and `script.js`).
- Guarantees instant, bulletproof rendering under any environment: local `file:///` execution, VS Code Live Server, iframe previewers, or GitHub Pages with zero flash of unstyled content (FOUC).

### 2. 💻 Interactive Developer Terminal (Code Tabs)
- Interactive desktop-inspired code editor artifact embedded in the Hero section.
- Working tab switcher supporting live syntax-highlighted files:
  - **`profile.json`**: Developer bio, academic major at SRMU, specialization, and availability.
  - **`stack.ts`**: TypeScript interface mapping the technical ecosystem.
  - **`shivi_ai.py`**: Python class structure representing the SHIVI AI conversational engine.

### 3. 📊 Animated Skill Progress Bars (3 Domain Categories)
- **Front-End & UI/UX**: HTML5 (90%), CSS3 & Grid Systems (88%), Modern JavaScript (82%), UI/UX Prototyping (80%).
- **AI & Data Science**: Python Programming (85%), Conversational AI Architecture (85%), Machine Learning Foundations (78%), Data Analysis (75%).
- **Tools & Workflow**: Git & GitHub (88%), VS Code & DevTools (90%), GitHub Pages CI/CD (85%), Web Performance (82%).
- Built with high-performance `IntersectionObserver` triggers, dark glass tracks, and glowing neon cyan-to-indigo gradient fills (`linear-gradient(90deg, #6366f1, #06b6d4)`).

### 4. 🤖 Flagship Project Showcase — SHIVI AI
- Dedicated asymmetrical showcase detailing **SHIVI AI**, an AI-powered conversational chatbot.
- Features an **in-portfolio live interactive simulator device** allowing visitors to click prompt chips (*"Who is Shivansh?"*, *"What are his skills?"*, *"How was SHIVI AI built?"*) or type custom queries with simulated typing delays and intelligent responses.
- One-click live launcher and copyable project link with visual checkmark feedback.

### 5. 🏛️ Academic & Identity Bento Grid
- Asymmetrical 4-card storytelling layout:
  - **Philosophy Card**: Personal manifesto on bridging algorithmic machine intelligence with human-centered front-end design.
  - **Academics Card**: Curriculum and core modules at Shri Ramswaroop Memorial University (SRMU).
  - **Synergy Card**: Visual intersection comparing Data Science & AI with UI/UX Web Craft.
  - **Live Status Card**: Active metrics, location, and project availability.

### 6. 🕒 Real-Time Indian Standard Time (IST) & Circular Scroll Progress
- Active real-time clock tracking India Standard Time (`Asia/Kolkata`) in both the Hero section and Footer.
- Floating back-to-top button featuring an SVG circular progress ring that dynamically fills as the user scrolls, smoothly returning to the top on click.

### 7. 📱 Bulletproof Mobile Navigation Drawer
- Fully hidden by default (`display: none !important`), activating as a blurred fullscreen drawer on hamburger toggle with keyboard `Escape` accessibility and click-outside dismissal.

## 🏃 Local Setup & Development

No package manager, node dependencies, or build tools are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shivanshtiwari-dsai/Portfolio.git
   cd Portfolio
   ```

2. **Run locally:**
   - Double-click `index.html` to open it directly in any modern browser, or
   - Use VS Code Live Server / any static HTTP server:
     ```bash
     npx serve .
     ```
